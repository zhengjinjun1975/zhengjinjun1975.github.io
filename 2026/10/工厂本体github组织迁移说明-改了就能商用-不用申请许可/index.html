工厂本体GitHub组织迁移说明，改了就能商用，不用申请许可

2026年10月18日 · AI驱动数字化转型

10 月 18 日上午，factory-ontology 在 GitHub 上换了主人。仓库从个人账户挪到 data3oil 组织名下，旧地址照常打开，自动跳到新页面。

对已经 clone 过的同学，什么都不用做。star 还在，fork 还在，提过的 issue 和 PR 还在，版本号接着往下走。迁移完成时这个仓库是 17 个 star、4 个 fork，一个没少。

这不是变天，是把仓库挂到了一个更稳的地方。

为什么是组织，不是继续挂在个人名下

先说一个常识。开源项目挂在个人名下，信任锚点就是那个人。哪天他换工作、改主意、仓库半年不更新，使用者没有任何办法，也没有任何依据判断这个项目还值不值得押。

工厂现场的系统不是这么运行的。一台设备、一条产线、一套问答系统，选型的时候要看供应商稳不稳定，要看承诺能不能兑现，要看出问题了找谁。

这些要求落到开源项目上，就是一个主体问题：谁在维护，谁对代码负责，谁接使用者的 issue。

这次迁移真正改的，是信任挂在哪。

从一个人名下，挪到一个主体名下。data3oil 组织背后是北京三油科技有限责任公司，2021 年 4 月成立，做地球物理与工业领域的 AI 落地。维护这个仓库的是这家公司，接 issue 的是这家公司，对开源边界负责的也是这家公司。

组织主页上写明了维护方、官网和联系方式。仓库 README 里有一段“谁在维护”，说的也是这件事。名字摆到明处，比任何承诺都省事。

为什么开源，边界在哪

经常有人问：核心算法开源出去，图什么。

图的是核对。工业现场的知识问答，吹牛的空间太大。说答案带证据，怎么证明？说确定性优先，凭什么信？

把源码摊开，建模怎么建、判定怎么走、答案的依据从哪来，任何人顺着代码核一遍，口径就不需要人担保。

README 里放着这类数字：UCI 公开数据集 61 个评测问题全中，阀门台账 9 比 9，九道自检门当前全绿。也放着不好看的：误答率 14.4%，诚实边界一节列了十条做不到的事。好看的和不好看的都摊着，才叫核对。

这次迁移同时做了一件事：给 README 补了一段“谁在用”。油田物探、精细化工、阀门制造、石油石化，只脱敏到行业，不写企业名。用在哪些现场是事实，写到行业为止，这也是边界。

开源的边界说在前头，免得后面纠缠。

算法层开源，Apache-2.0。可以自由下载、部署、修改、商用，不需要申请许可，用它服务自己的客户也不用向我们付费。行业落地实施由我们做，按项目收费。

这两种工作性质不同。算法原子是可以复用的公共资产，落地实施是贴着现场约束的工程服务。后者省不掉，也不该省。真想省掉这一段，自己下载代码部署就行，那正是开源的意思。

还有一条从建库第一天起就没变过的红线：仓库不接收任何真实工厂数据，示例一律合成数据。数据不出厂不是口号，是代码结构决定的，核心代码只依赖 Python 标准库，本地建模本地问答，可以完全离线。

顺手做的几件小事

迁移不止是改个归属。组织主页从零搭了起来：一句话定位，核心项目，联系方式，都在明处。

Discussions 开了张。以前使用问题、场景想法没有地方聊，只能挤 Issue；现在问题归问题，bug 归 bug。使用类的问题本来就该有公开答案，后来的人搜得到，不用再问一遍。

公开树也过了一遍。开发时期写给自己看的东西混了一些在里面，比如内部的对齐方案和评估底稿。这些不该出现在一个组织门面上，一并撤了出去。本地都留着，丢不了。

代码一行没动。改的是仓库摆在世人面前的样子。

你现在能做什么

本地已经 clone 过的，把地址换一下就行：

git remote set-url origin https://github.com/data3oil/factory-ontology.git

其他几件事，按需要来：

  • Star。用得顺手就点一个，让更多需要工厂数据问答的人找到它。
  • Issue。使用问题、场景想法，去 Discussions 聊；真 bug 留 Issue，附上复现命令：数据文件加问题加期望和实际输出。
  • PR。欢迎。代码加对应测试，跑通 pytest；涉及问答能力的改动，附上 benchmark 结果。
  • 读 README。架构说明、实测数据、九道自检门的结果都在里面，包括它不擅长什么，那部分写得同样仔细。

官网同步开了一个开源项目页，为什么开源、边界在哪、怎么参与，一页说清。小程序里的产品卡片也带上了开源角标，等备案审批下来随版本发布。

四个阵地从此说的是同一套口径：算法层开源，落地实施我们做；答案要能核对，代码摊开给人看。

信任是挂出来的

个人名下到组织名下，改的不是代码，是信任挂在哪。

代码一天没变。变的是仓库背后那个名字：从一个人，变成一家把名字和责任都摆在明处的公司。

开源这件事我们看得重，不是因为大方，是因为核对。现场的问题够复杂，答案就更要能核对，代码摊开给人看，维护的人敢把名字写在上面。

工厂本体在 data3oil 名下接着走。你的 star，我们记着。
